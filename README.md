# 🗼 운명의 탑 (Tower of Fate)

모바일 세로형 **확률 탑쌓기 게임**. 매 턴 제시되는 세 블록 중 하나를 골라
밤하늘 위 부유섬에 탑을 쌓는다. 블록을 놓을 때마다 붕괴 판정이 실행되고,
무너지면 금고에 저장하지 않은 점수를 모두 잃는다. **"한 층만 더 쌓을까,
지금 탈출할까?"** — 이 결정이 매 턴 진짜 기댓값 문제가 되도록 설계했다.

## 실행 방법

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
npm test         # Vitest 단위 테스트 (위험/점수/난수/선택지/분석)
npm run sim      # 몬테카를로 밸런스 시뮬레이터 (전략별 3000판)
```

`http://localhost:5173/?debug` 로 접속하면 판정 난수·유효 확률·무게중심·
최악 오버행을 보여주는 디버그 패널이 켜진다.

## 게임 시스템

- **블록 5종** — 나무판(넓고 안전) · 돌 블록(무거움) · 유리 왕관(고득점·깨지기 쉬움) ·
  거대 금괴(최고 득점·최고 위험) · 기초석(탑 안정화).
  선택지는 매 턴 가중 확률로 3개가 뽑힌다.

- **붕괴 위험 = 확률 결합** — 위험 요인(치우침·지지면 부족·무게·재질·높이)을
  각각 독립 원인의 확률 pᵢ로 계산하고 `1 − ∏(1 − pᵢ)` 로 결합한다.
  덧셈이 아니라서 요인이 쌓여도 100%를 넘지 않고, 완화 요인(안정된 중심·
  기초석·초반의 가호)은 배율로 곱해진다. 모든 요인은 UI 칩으로 노출되며
  **표시 확률과 판정 확률은 항상 동일하다.**

- **층별 정역학 (오버행)** — 모든 층에 대해 "그 층 위 부분탑의 무게중심"이
  받침 폭 안에 있는지 검사하고, 최악의 층을 위험으로 환산한다. 조금씩
  같은 방향으로 내밀면 조화급수처럼 상당한 오버행 탑도 가능하지만,
  한 층이라도 크게 내밀면 위험이 치솟는다.

- **점수 = 기댓값 게임** — 획득 점수는
  `블록 점수 × (1 + 1.5p) + 걸린 점수 × max(0, p − 0.1)/(1−p) × 0.9`.
  스테이크 배당은 **위험 10%를 넘는 배치에만** 붙는다 — 운명은 안전한
  자에게 배당을 주지 않는다. 안전한 중앙 배치는 블록 점수만 얻으므로,
  걸린 점수가 커질수록 중앙 반복 쌓기는 명백히 기댓값 마이너스가 되고
  (복리 착취 불가), 점수를 불리려면 문턱 위의 진짜 베팅이 필요하다.
  베팅에도 하우스 엣지(0.9)가 있어 언젠가는 탈출이 수학적 정답이 된다 —
  그 지점을 읽는 것이 실력. 조준 중 HUD에 **성공 보상·실패 손실·기댓값**이
  실시간으로 표시된다.

- **운명의 표식** — 매 턴 탑 좌우에 번갈아 나타나는 황금 표식. 맞히면
  PERFECT: 블록 점수 ×1.25, 위험 일부 상쇄("표식의 가호"), 그리고 **콤보가
  이어질수록 하우스 엣지가 깎인다** (0.9 → 최대 0.97). 시뮬레이션 기준
  표식 노림수의 상위 10% 기록은 중앙 안정 플레이를 앞선다 — 분산이 큰
  잭팟 스타일.

- **운명의 시험** — 2층부터 자동으로 나타나는 3배치짜리 미니 도전
  (표식 2회 · 다른 재료 3연속 · 위험 25%+ 생존 · 좌우 교차 3연속).
  선택도 모달도 없이 HUD 칩 하나로 뜨고, 성공하면 `25 + 탑 점수의 15%`가
  금고로 직행하며, 실패해도 처벌 없이 흘러간다. 존재 이유는 하나 —
  "안전하게 중앙에만 쌓기"가 언제나 정답이 되지 않게, 중앙에서 벗어나는
  플레이에 값을 지불하는 것.

- **체크포인트** — 5층마다 탑 위 점수의 20→30→40%가 금고에 자동 저장된다.

- **층화 판정 난수** — 붕괴 판정 난수는 [0,1)을 8구간으로 나눈 셔플 순서로
  뽑는다. 난수 하나하나는 여전히 정확한 균등분포지만(표시 == 판정 유지),
  8번의 판정 안에서 극단적 행운/불운의 연속이 수학적으로 불가능해진다.

- **오늘의 운명 = 본 게임** — 모든 판은 날짜 시드로 시작한다. 블록
  선택지와 운명의 시험 순서가 오늘 하루 동안 고정되어 모두가 같은
  블록을 받고, 붕괴 판정 난수만 각자의 운이다. 같은 조건에서 겨루는
  공정한 일일 리더보드가 게임의 기본 형태다. (튜토리얼 연습 판만
  비시드 난수를 쓴다)

## 밸런스 시뮬레이터

`npm run sim` 은 게임과 완전히 같은 순수 함수(computeRisk / computeGain /
judgeCollapse)로 전략 봇들을 돌려 평균 점수·중앙값·상위 10%·붕괴율을
비교한다. 탐욕(EV≥0이면 계속), 신중(분산 회피), 고정층 탈출 전략이
기본 제공되며, `src/game/config/balance.ts` 수치를 바꾸면 여기서 근거를
확인할 수 있다. 표시 확률 == 판정 확률이므로 시뮬 분포가 곧 실제 게임의
기대 분포다.
